Task 13: NumPy Random Sampling

Project Overview
This project focuses on generating random numbers and samples using NumPy. It demonstrates random integers, floating-point numbers, random samples from arrays, simulated student marks, and reproducible results using random seeds.

Objective
Understand random data generation and its importance in data science experiments.

Tools
- Python
- NumPy
- Jupyter Notebook

Deliverables
- Random integers and floating-point numbers
- Random samples from an array
- Reproducible results using a random seed
- Simulated student marks
- Python script and Jupyter Notebook

Key Functions
- `np.random.randint()` — random integers
- `np.random.random()` — floating-point values from 0 to 1
- `np.random.uniform()` — floating-point values in a range
- `np.random.choice()` — random samples
- `np.random.seed()` — reproducible pseudo-random results
